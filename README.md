# مقاضي أوفر — المدينة المنورة

[التطبيق المنشور](https://saud-saud11.github.io/magadi_awfar/)

واجهة Flutter عربية للبحث عن مقاضي البيت، جمع السلة بالصوت، وحفظ أصناف متكررة للمتابعة، مع خدمة متابعة مستضافة على Sites / D1، وخادم FastAPI بديل للتشغيل المحلي.

## حالة المصادر

- يُجرّب البحث في كتالوج الدانوب الإلكتروني العام. لا يظهر سعر إلا عند وصول قراءة صالحة من المصدر؛ قد يتوقف المصدر أو تتغير واجهته.
- تغطية حي المستخدم والمخزون النهائي ورسوم التوصيل والخدمة تُؤكد لدى المتجر. السعر المعروض ليس وعدًا بإمكانية الطلب محليًا.
- نينجا، هنقرستيشن، كيتا، أمازون ناو وبقية المصادر غير المربوطة تظهر «يحتاج إعدادًا». لا تُولّد أسعار منافسين من سعر متجر واحد.
- عند تعذر الجلب، يُستخدم كتالوج أصناف بلا أسعار. يمكن حفظ الأصناف محليًا، وتبقى المتابعة على الخادم معلقة إلى أن يوجد منتج مطابق وسعر موثوق.

## ما يعمل

- فصل الحجم المطلوب عن الأحجام البديلة، وترتيب عروض المنتج حسب السعر مع وقت آخر جلب.
- صورة المنتج من بيانات المصدر، مع بديل عند تعذر تحميلها ودعم صور الويب دون وسيط صور عام.
- سلة محفوظة على الجهاز؛ مجموع المنتجات بالهللات، والأصناف الناقصة والرسوم غير المعروفة موضحة.
- أوامر عربية للصوت/النص: إضافة، كمية، تراجع ونفي. الأوامر المحلية تعتمد قواعد وكتالوجًا؛ التعرف على الصوت يعتمد دعم المتصفح. لا يوجد ادعاء بربط نموذج لغوي سحابي لمجرد وجود مفتاح API.
- متابعة بسعر أساس موثق، مطابقة الحجم وعدد العبوات، ساعات هدوء وإرسال Web Push فعلي بعد تهيئة الخادم.
- جلسة ضيف عشوائية لكل جهاز، وإجراءات المتابعة مقيدة بامتلاك الجلسة. لا توجد مزامنة حساب بين الأجهزة بعد.

## التشغيل والاختبار

تُختبر الواجهة باستخدام Flutter 3.47.7 / Dart 3.13.5، والخادم باستخدام Python 3.12.

```bash
cd backend
python -m venv .venv
# فعّل البيئة الافتراضية وفق نظامك، ثم:
pip install -r requirements.txt
python -m pytest -q
uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1
```

وفي نافذة أخرى:

```bash
cd frontend
flutter pub get
flutter analyze
flutter test
flutter run -d chrome --web-port 8080 --dart-define=API_BASE_URL=http://127.0.0.1:8000/api/v1
```

[تفاصيل تجهيز الخادم والتنبيهات والنشر](docs/RELIABILITY_UPDATE_AR.md).

## الاستضافة الحالية

الواجهة على GitHub Pages، وخدمة التطبيق على [مقاضي أوفر API](https://magadi-awfar-api.alhuwayfi-shop.chatgpt.site). لا يحتاج هذا الإعداد اشتراك استضافة خارجيًا مدفوعًا؛ يخضع لحدود حساب Sites والمهام السحابية. ليس وعدًا بخدمة غير محدودة.

الخدمة العامة تمرر مسارات التطبيق إلى خادم خاص بالمالك على Sites مع قاعدة D1 دائمة. مفتاح المرور للخادم ومفتاح VAPID الخاص محفوظان في إعدادات الخادم السرية، ولا يدخلان مستودع GitHub أو Flutter. الصوت وحساب السلة يستمران بالمنطق المحلي المختبر.

بعد كل تعديل على main تنفذ GitHub Actions اختبارات Python وFlutter ثم تبني وتنشر الواجهة مع عنوان الخادم. تُنقل الملفات المبنية إلى فرع gh-pages المسموح له بالنشر، وتُنشر منه مع بقاء قواعد حماية البيئة كما هي. ملف release.json المنشور يحدد نسخة النشر.

مصدر خدمتي Sites محفوظ في مستودعي المصدر المرتبطين بهما؛ تغييرات backend/ هنا تخص البديل المحلي ولا تنشر تلقائيًا إلى Sites. تعليمات مراقبة الأسعار موجودة في OPERATIONS.md داخل مصدر الخدمة الخاصة. المهمة المرتبطة بالخدمة مفعلة كل ساعة (حد الحساب الحالي)، مع زر تحديث يدوي في التطبيق.
