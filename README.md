تطبيق حقيقي متكامل باللغة العربية لمقارنة أسعار السوبرماركت ومتاجر البقالة في **المدينة المنورة، المملكة العربية السعودية**، يربط بين تطبيق محمول حديث (Flutter) وخادم قوي (FastAPI) مع سلة مشتريات صوتية بالذكاء الاصطناعي تفهم اللهجة السعودية ومعمارية موصلات مرنة ومحرك مطابقة صارم وحسابات مالية دقيقة بالهللات.

---

## 🌟 أبرز المميزات

1. **نطاق محلي دقيق بالمدينة المنورة:**
   - تغطية أحياء المدينة المنورة (سلطانة، قباء، العزيزية، الخالدية، الرانوناء، العريض، الدفاع، شظاة، شوران، باقدو، الحرم، إلخ).
   - ربط النتائج بالفروع الفعلية ومناطق التوصيل (مثل فرع محطة قطار الحرمين للدانوب، فرع النور مول لبنده، فرع الراشد مول لكارفور).
2. **محرك مطابقة صارم (Strict Matching):**
   - يدعم العربية والإنجليزية والأرقام العربية والإنجليزية.
   - لا يخلط بين الأحجام: استعلام مثل «نوتيلا 500 جرام» لا يخلط مع 400g أو 750g، بل يعرض رسالة توضيحية صريحة مع قسم للأحجام البديلة وحساب سعر الـ 100 جرام.
   - يفرّق بين العبوة الواحدة وعروض العبوتين (Multi-pack).
3. **حساب مالي دقيق بالهللات:**
   - عمليات مالية كأعداد صحيحة `int` لتفادي أخطاء التقريب.
   - وضعين: أقل سعر للمنتج vs أقل إجمالي شامل التوصيل.
   - الرسوم المجهولة لا تُعتبر صفرًا بل يظهر تنبيه «الإجمالي يُؤكد لدى المتجر».
4. **سلة المقاضي الذكية (Smart Basket):**
   - مقارنة تكلفة السلة كاملة بين المتاجر.
   - توضيح السلات الناقصة والبدائل المقترحة.
   - اقتراح تقسيم السلة عند وجود توفير حقيقي بعد احتساب رسوم التوصيل المنفصلة.
5. **لوحة موثوقية المصادر:**
   - بيان شفاف لحالة كل متجر: متصل، يحتاج إعداد، غير مدعوم.

## 🏗️ البنية والتقنيات

- **الواجهة الأمامية (Frontend):** Flutter 3.35+ (Dart 3.9) مع تصميم زمردي حديث ودعم RTL كامل.
- **الخادم (Backend):** Python 3.12 + FastAPI + Pydantic V2.
- **قاعدة البيانات:** SQLAlchemy 2.0 (SQLite محليًا / متوافق مع PostgreSQL).
- **الموصلات:** معمارية معزولة تمنع تعطل التطبيق عند فشل أي متجر فردي.

